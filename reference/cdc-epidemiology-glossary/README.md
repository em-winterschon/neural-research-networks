# CDC Epidemiology Glossary - reference

Generative source for the CDC Epidemiology Glossary PDF that Eva
Winterschon uses as a reference document.

- `cdc-epidemiology-glossary.tex` - the LaTeX source (the generative
  code). Compiling it produces the glossary PDF.
- The compiled PDF (12 pages, A-Z) is a build artifact of this source.
  The canonical copy lives in Eva's Sourasky intake packet (item 5);
  it is not committed here because the connector used for this push
  cannot carry binary files intact.
- Source material: CDC Epidemiology Glossary, Reproductive Health,
  page dated May 14, 2024 -
  https://www.cdc.gov/reproductive-health/glossary/
  (U.S. federal government content, reproduced for offline reference.)

Use in this repo: reference terminology. Selected definitions from
this glossary are also used as reference terms in Eva's Sourasky
complaint materials.
